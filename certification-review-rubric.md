# JM Brandify Certification Review Rubric

This document is for internal reviewer and AI-assisted evaluation use only. It should not be displayed on the public roadmap page.

For the full scored scorecard, see `resources/certificates/certification-review-scorecard.md`.

A short reference to certification resources is also included in `README.md` under the Certification Resources section.

## CRM Foundation — 20 pts
Criteria:
- Business profile configured
- Contacts organized
- Tags and Smart Lists created
- Custom Fields used correctly
- User permissions set

## Lead Capture Funnel — 20 pts
Criteria:
- Funnel page exists
- Form captures required data
- Thank-you page works
- Lead enters CRM
- Source tracking included

## Workflow Automation — 25 pts
Criteria:
- Trigger configured correctly
- Email/SMS follow-up works
- Pipeline stage updates
- Internal notification exists
- If/Else or wait step used properly

## SaaS Snapshot / Reusability — 15 pts
Criteria:
- Snapshot includes core assets
- Naming is organized
- Custom values documented
- Deployment steps included

## Client Provisioning & Documentation — 20 pts
Criteria:
- Onboarding process documented
- SOP included
- Client handover checklist included
- Final project summary submitted

## Scoring levels
- 90–100 = Certified
- 75–89 = Passed with Recommendations
- 60–74 = Revision Needed
- Below 60 = Not Yet Passed

## AI Review Guidelines
AI should check for:
- Evidence completeness
- Clear screenshots
- Working URLs
- Logical workflow structure
- Correct naming conventions
- Proof that the system solves a real business problem

AI should NOT approve submissions based only on claims.
Each score must be supported by visible evidence or documentation.

## Final note
Human review is recommended before issuing final certification.
