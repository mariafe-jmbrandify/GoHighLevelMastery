📚 GoHighLevel Glossary
A quick reference for the most important GHL concepts used throughout this roadmap.
Sub-Account
A separate client workspace inside GoHighLevel that keeps contacts, funnels, and automations segmented.
Workflow
An automation sequence that uses triggers, actions, delays, and conditional branches.
Snapshot
A reusable bundle of funnels, workflows, pipelines, and settings that can be cloned into another account.
Pipeline
A visual sales board for tracking opportunities through stages and revenue progress.
Smart List
A dynamic contact list filtered by tags, behavior, custom fields, or saved query rules.
SaaS Mode
The reseller layer that lets agencies provision, bundle, and monetize sub-accounts.
Custom Field
A user-defined data field for storing unique contact or opportunity details.
Webhook
A push notification from GoHighLevel to an external app or service when an event occurs.
API v2
The GoHighLevel developer API for integrations, data access, and custom apps.
White-label
Branding the GoHighLevel platform with your own agency identity for clients.
