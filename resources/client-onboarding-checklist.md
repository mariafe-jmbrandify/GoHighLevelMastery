## Pre-Onboarding (Week Before)

- [ ] Key team contacts identified

### System Preparation
- [ ] Sub-account created in GHL
- [ ] Access credentials prepared
- [ ] Workflows & templates imported (if applicable)
- [ ] User roles & permissions configured
- [ ] Phone number/SMS setup (if needed)

### Communication

- [ ] Pre-kickoff questionnaire sent
