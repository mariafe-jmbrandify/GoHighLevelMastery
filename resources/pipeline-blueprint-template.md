## Stage Architecture

### Stage 1: Lead
**Description:** New, unqualified prospect entering the funnel
**Entry Criteria:**
- Form submission / Referral / Lead import / Manual add

**Move-Forward Criteria (to Qualified):**
- [ ] Contact info verified
- [ ] Initial interest confirmed
- [ ] Basic qualification questions answered
- [ ] Score threshold met: ____ points

**Actions on Entry:**
- [ ] Send welcome email
- [ ] Assign to sales rep
- [ ] Add to workflow
- [ ] Schedule follow-up

**Typical Duration:** 2-5 days
**Default Owner:** ___________________________

---

### Stage 2: Qualified
**Description:** Contact has shown interest and meets qualification criteria
**Entry Criteria:**
- Lead has budget [ ] Contact has authority [ ] Need identified
- Timeline realistic [ ] Fit confirmed

**Move-Forward Criteria (to Proposal):**
- [ ] Discovery call completed
- [ ] Needs assessment documented
- [ ] Budget confirmed: $______________
- [ ] Decision timeline: _______________

**Actions on Entry:**
- [ ] Schedule discovery call
- [ ] Send qualification email
- [ ] Create project scope document
- [ ] Notify manager

**Typical Duration:** 5-10 days
**Default Owner:** ___________________________

---

### Stage 3: Proposal
**Description:** Custom proposal/quote prepared and sent to prospect
**Entry Criteria:**
- All discovery completed
- Scope of work defined
- Pricing determined

**Move-Forward Criteria (to Won/Closed Lost):**
- [ ] Proposal approved by prospect
- [ ] Contract signed
- [ ] Payment received (if applicable)

**Actions on Entry:**
- [ ] Generate proposal
- [ ] Send proposal email
- [ ] Schedule review call
- [ ] Set follow-up reminder

**Typical Duration:** 5-14 days
**Default Owner:** ___________________________

---

### Stage 4: Negotiation (Optional)
**Description:** Discussing terms, pricing, or scope adjustments
**Entry Criteria:**
- [ ] Client requested changes
- [ ] Additional discovery needed
- [ ] Internal approval required

**Move-Forward Criteria:**
- [ ] Agreement reached on terms
- [ ] Final approval obtained
- [ ] Ready for execution

**Actions on Entry:**
- [ ] Document requested changes
- [ ] Internal review/approval
- [ ] Revised proposal preparation

---

### Stage 5: Won / Closed Lost
**Description:** Deal closed (won or lost)

**Won Actions:**
- [ ] Send congratulations email
- [ ] Onboarding workflow triggered
- [ ] Invoice generated
- [ ] Move to operations team

**Closed Lost Actions:**
- [ ] Document reason for loss
- [ ] Send thank you/stay-in-touch email
- [ ] Tag for future nurture
- [ ] Schedule re-engagement

## Lead Scoring System

**Lead Sources (add points):**
- Website referral: +10
- Inbound inquiry: +15
- Referral partner: +20
- Cold outreach: +5

**Engagement (add points per action):**
- Email open: +2
- Link click: +5
- Website visit: +3
- Page view (multiple): +1 each

**Qualification (add points):**
- Has budget: +25
- Decision authority: +20
- Timeline defined: +15
- Need identified: +10

**Hot Lead Threshold:** 75+ points → Immediate sales call
